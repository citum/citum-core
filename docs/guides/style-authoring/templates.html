Templates and Type Variants

Build citation and bibliography output from explicit template components.

Template components

Templates are ordered component lists. Each component names the data it renders and optional formatting around that data.

bibliography:
  template:
    - contributor: author
    - date: issued
      form: year
      wrap: parentheses
      prefix: " "
    - title: primary
      prefix: " "
    - title: parent-serial
      emph: true
      prefix: ". "
ComponentCommon use
contributorauthor, editor, translator, and other contributor roles
dateissued, accessed, original-date, and other date fields
titleprimary title, parent title, collection title
numbervolume, issue, pages, edition, citation number
termlocalized labels such as page, volume, or editor
variabledirect field output such as publisher, DOI, URL

Groups and first-match fallback

group: wraps child components and renders them together, joined by its own delimiter. By default every non-suppressed child renders (select: all). Set select: first to render only the first child that produces non-empty output — the declarative way to say "try this, and if it's empty, try that" without a pair of opposite render-when conditions.

# DOI if present, else URL
    - select: first
      group:
      - variable: doi
        prefix: "https://doi.org/"
      - variable: url
        prefix: " "

A candidate can be a bare term-only message, since each candidate is judged only on whether it produces output — no group-level "backed by real data" check applies in select: first mode:

# Container genre if present, else the term "Episode"
    - select: first
      group:
      - variable: genre
        text-case: capitalize-first
      - message: term.episode
        text-case: capitalize-first

A select: first group needs at least two children and cannot also declare delimiter. See the Style Guide's Groups and First-Match Fallback section for the full comparison with render-when, substitute, and date-fallback.

Type variants

Use type-variants when a reference type needs a different bibliography structure. Prefer small diff variants when the default template is mostly right.

bibliography:
  template:
    - contributor: author
    - title: primary
    - variable: publisher
      prefix: ". "

  type-variants:
    article-journal:
      modify:
        - match:
            title: primary
          suffix: ". "
      add:
        - after:
            title: primary
          component:
            title: parent-serial
            emph: true
      remove:
        - match:
            variable: publisher

Selectors are partial component matches. { title: primary } matches a primary title component even when that component also has affixes or emphasis.

Citation modes

Use mode-specific citation blocks when narrative and parenthetical citations diverge.

citation:
  non-integral:
    wrap: parentheses
    template:
      - contributor: author
        form: short
      - date: issued
        form: year
        prefix: ", "
  integral:
    delimiter: " "
    template:
      - contributor: author
        form: short
      - date: issued
        form: year
        wrap: parentheses

Note styles can also define subsequent and ibid templates for repeated citations.
